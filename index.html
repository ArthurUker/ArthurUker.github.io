About Me

关于我

I am a Ph.D.-trained biomedical engineer working at the interface of molecular diagnostics, digital microfluidic platforms, nucleic acid testing, and structured, data-supported R&D workflows.

我是一名具有生物医学工程博士背景的研发人员，主要工作方向位于分子诊断、数字微流控、核酸检测平台和结构化、数据支持型研发流程的交叉领域。

I combine wet-lab experience in extraction and amplification-based detection with practical digital system development for laboratory informatics, project coordination, and scientific documentation.

我将核酸提取与扩增检测等 wet-lab 经验，与实验室信息化、项目协同和技术文档系统建设结合起来，推动更高效的转化研发执行。

R&D Project Management Platform

Cross-functional R&D coordination and milestone tracking

跨职能研发协同与里程碑追踪

  • Challenge: Diagnostic R&D projects often involve fragmented tasks across reagent development, instrument engineering, software configuration, documentation, and deployment testing.
  • Approach: A lightweight coordination platform was designed to organize milestones, tasks, technical notes, user roles, and progress tracking.
  • Outcome: The system provides a clearer view of project status, task ownership, and documentation progress.
  • Role: Workflow design, requirement definition, deployment troubleshooting, documentation, and iterative improvement.
  • 问题背景：诊断研发项目通常涉及试剂、仪器、软件配置、技术文档和部署测试等多个环节，任务容易分散。
  • 解决思路：设计轻量级研发协同平台，用于组织里程碑、任务、技术记录、用户角色和进度追踪。
  • 结果与意义：系统有助于更清晰地展示项目状态、任务归属和文档进度。
  • 我的角色：工作流设计、需求定义、部署问题排查、文档整理和迭代优化。

Sample Data Hub

Sample metadata organization and collaborative testing records

样本元数据组织与协作式检测记录管理

  • Challenge: Sample testing information can become fragmented across spreadsheets, local files, and inconsistent record formats.
  • Approach: A collaborative data hub was designed to organize sample metadata, testing records, experimental parameters, and result review workflows.
  • Outcome: The project demonstrates how structured data workflows can improve sample information consistency and traceable record management.
  • Role: Workflow analysis, data model thinking, interface logic design, documentation, and iterative debugging.
  • 问题背景：样本检测信息容易分散在表格、本地文件和不一致的记录格式中，影响追溯与协作。
  • 解决思路：设计协作式样本数据平台，用结构化方式组织样本元数据、检测记录、实验参数和结果审核流程。
  • 结果与意义：该项目展示了结构化数据工作流如何改善样本信息一致性和可追溯记录管理。
  • 我的角色：工作流分析、数据模型思考、界面逻辑设计、文档整理和迭代调试。

Laboratory Workflow & Reporting System

Laboratory sample tracking and structured report generation

实验室样本追踪与结构化报告生成

  • Challenge: Applied testing laboratories require clear workflows for sample registration, testing records, result aggregation, and report preparation.
  • Approach: A web-based laboratory workflow system was developed to organize sample registration, testing steps, result records, and report-oriented outputs.
  • Outcome: The project demonstrates how lightweight laboratory informatics tools can improve workflow transparency and structured reporting.
  • Role: Workflow design, data organization, interface review, report logic planning, and technical documentation.
  • 问题背景：应用检测实验室需要清晰管理样本登记、检测记录、结果汇总和报告生成。
  • 解决思路：开发网页化实验室工作流系统，用于组织样本登记、检测步骤、结果记录和报告导向输出。
  • 结果与意义：该项目展示了轻量级实验室信息化工具如何改善流程透明度和结构化报告能力。
  • 我的角色：工作流设计、数据组织、界面审查、报告逻辑规划和技术文档整理。

Macao IVD Registration Knowledge System

IVD regulatory knowledge organization and registration workflow structuring

IVD 法规知识组织与注册流程结构化

  • Challenge: IVD registration-related policy documents, guidance files, evidence requirements, and registration tasks can be difficult to manage when information is scattered.
  • Approach: A structured knowledge system was designed to organize guidance documents, document categories, update records, and registration-related task logic.
  • Outcome: The project demonstrates how structured digital systems can support regulatory knowledge management, document traceability, and registration workflow planning.
  • Role: Policy document review, information architecture, database field planning, module requirement definition, and documentation.
  • 问题背景：IVD 注册相关政策文件、指导原则、证据要求和注册任务容易分散，影响更新追踪和资料准备。
  • 解决思路：构建结构化知识系统，用于组织法规文件、文档类别、更新记录和注册相关任务逻辑。
  • 结果与意义：该项目展示了结构化数字系统如何支持法规知识管理、文档可追溯和注册流程规划。
  • 我的角色：政策文件审查、信息架构设计、数据库字段规划、模块需求定义和文档整理。

Digital Microfluidic Documentation Builder

Technical documentation and scientific communication for digital microfluidic platforms

面向数字微流控平台的技术文档与科学传播

  • Challenge: Digital microfluidic platforms require clear communication across scientific, engineering, product, and stakeholder audiences.
  • Approach: A documentation builder was designed to structure technical specifications, application scenarios, platform descriptions, and brochure-style materials.
  • Outcome: The project demonstrates the ability to translate complex platform concepts into reusable technical communication materials.
  • Role: Content structure design, technical narrative organization, documentation workflow planning, and implementation review.
  • 问题背景：数字微流控平台需要在科研、工程、产品和外部合作方之间进行清晰技术表达。
  • 解决思路：设计文档生成工具，用于结构化组织技术规格、应用场景、平台描述和宣传册式材料。
  • 结果与意义：该项目展示了将复杂平台概念转化为可复用技术沟通材料的能力。
  • 我的角色：内容结构设计、技术叙事组织、文档工作流规划和实现审查。
