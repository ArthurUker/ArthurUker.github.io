## 1. 本作品集的目的

本 Digital Portfolio 是 **Renkang Guo, Ph.D. / 郭仁康博士** 的专业型、证据型个人网站。

它的目标不是简单展示网页设计或代码能力，而是系统呈现一个清晰、可信、面向国际生物医药与 IVD 行业的专业身份：

- 转化分子诊断
- 数字微流控
- 核酸检测
- sample-to-answer 平台开发
- 实验室信息化
- 结构化研发流程
- 科学与技术文档
- 跨职能研发协同

该作品集应帮助国际生物技术公司、制药企业、IVD 产品开发团队、转化研究团队、诊断平台团队和学术合作方理解：

> 我的背景如何连接实验科学、工程平台、数据工作流和产品化研发执行。

本作品集 **不是一个通用软件开发者作品集**。

网页系统、数据工具、仪表盘和数字化平台应被呈现为：

> 用于解决实验室研发、样本数据管理、研发协同和技术文档问题的辅助工具。

它们不是我的主要职业身份。

## 5. 最重要的定位规则

### 数字化工具是支持能力，不是主身份

在描述网站、仪表盘、数据库、项目管理系统或信息化系统时，必须始终把它们连接到实验室或研发问题。

推荐表达：

> 我构建轻量级数字化工具，用于改善样本数据组织、研发可追溯性、技术文档流程和跨职能协同。

不推荐表达：

> 我是一名全栈开发者，开发可扩展的网页应用。

推荐表达：

> 该系统支持实验室工作流中的结构化样本记录和结果报告。

不推荐表达：

> 这是一个面向企业客户的生产级网页应用。

核心原则：

> 代码能力是方法，研发问题是目标；数字工具是桥梁，分子诊断与平台研发才是主线。

## 15. 推荐案例内容

### 15.1 R&D Project Management Platform / 研发项目管理平台

**Focus / 重点：** 跨职能研发协同与里程碑追踪

#### Challenge / 问题背景

诊断产品开发通常涉及试剂研发、仪器工程、软件配置、技术文档和部署测试等多个环节。不同任务如果分散在聊天记录、表格和本地文件中，会导致项目状态不透明、任务责任不清晰和文档追踪困难。

#### Approach / 解决思路

设计并构建一个轻量级研发项目协同平台，用于组织项目里程碑、任务、技术记录、用户角色和进度追踪，使复杂研发任务能够以结构化方式呈现。

#### Outcome / 结果与意义

该系统有助于更清晰地展示项目状态、任务归属和文档进度，支持更透明的研发协同和项目推进。

#### My Role / 我的角色

工作流设计、需求定义、系统测试、部署问题排查、文档整理和迭代优化。

#### Tools / Methods / 工具与方法

TypeScript、React、NestJS、数据库支撑型工作流设计、GitHub、Nginx 部署。

---

### 15.2 Sample Data Hub / 样本数据协作平台

**Focus / 重点：** 样本元数据组织与协作式检测记录管理

#### Challenge / 问题背景

样本检测信息容易分散在多个表格、本地文件和不一致的记录格式中，导致样本来源、检测参数、结果记录和协作编辑过程难以追溯。

#### Approach / 解决思路

设计协作式样本数据平台，用结构化方式组织样本元数据、检测记录、实验参数和结果审核流程，减少孤立表格和分散记录带来的信息不一致问题。

#### Outcome / 结果与意义

该项目展示了结构化数据工作流如何改善样本信息一致性、协作编辑和可追溯记录管理。

#### My Role / 我的角色

工作流分析、数据模型思考、界面逻辑设计、文档整理和迭代调试。

#### Tools / Methods / 工具与方法

JavaScript、结构化数据工作流、数据库导向设计、GitHub。

---

### 15.3 Laboratory Workflow and Reporting System / 实验室流程与报告系统

**Focus / 重点：** 实验室样本追踪与结构化报告生成

#### Challenge / 问题背景

应用检测实验室需要清晰管理样本登记、检测记录、结果汇总和报告生成。如果流程依赖人工表格和分散文件，容易影响数据一致性、报告效率和流程透明度。

#### Approach / 解决思路

开发基于网页的实验室工作流系统，用于组织样本登记、检测步骤、结果记录和报告导向的输出流程。

#### Outcome / 结果与意义

该项目展示了轻量级实验室信息化工具如何改善流程透明度和结构化报告能力。

#### My Role / 我的角色

工作流设计、数据组织、界面审查、报告逻辑规划和技术文档整理。

#### Tools / Methods / 工具与方法

JavaScript、SQL 导向数据组织、网页化实验室工作流设计。

### 15.4 Macao IVD Registration Knowledge System / 澳门 IVD 注册知识系统

**Focus / 重点：** IVD 法规知识组织与注册流程结构化

#### Challenge / 问题背景

IVD 注册相关政策文件、指导原则、证据要求和产品注册任务往往分散在不同文档中。如果缺少结构化管理，容易造成法规更新难以追踪、注册资料准备不系统、任务分工不清晰。

#### Approach / 解决思路

构建结构化知识系统，用于组织法规指导文件、注册相关任务、文档类别和更新记录，为 IVD 产品注册规划提供信息架构支持。

#### Outcome / 结果与意义

该项目展示了结构化数字系统如何支持法规知识管理、文档可追溯和注册流程规划。

#### My Role / 我的角色

政策文件审查、信息架构设计、数据库字段规划、模块需求定义和文档整理。

#### Tools / Methods / 工具与方法

结构化知识库设计、SQL 规划、Markdown 文档、基于 GitHub 的版本管理。

#### 重要措辞规则

不要声称该系统提供法律意见、官方法规批准或经过认证的合规结论。

推荐写法：

> This system supports regulatory knowledge organization and registration workflow planning.

避免写法：

> This system ensures regulatory compliance or guarantees successful product registration.
